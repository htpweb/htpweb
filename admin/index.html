Tarifas de entrega

Configura cuánto cobra el DELIVERY por llevar un pedido al cliente.

Configuración principal

Esta configuración pertenece al DELIVERY_ADMIN. MASTER decide si este DELIVERY puede usar Tarifa fija, Por distancia o ambas. El cálculo final del envío siempre lo realiza el backend.

Tarifa por kilómetro — Día / Noche

El DELIVERY configura un costo por km para el día y otro para la noche. El cliente no selecciona la tarifa: el backend aplica automáticamente la correcta según la hora del pedido.

Cobertura del DELIVERY

Los locales disponibles se determinan por las zonas aprobadas para el DELIVERY.

Territorio base — MASTER

MASTER define el cantón y el catálogo global de zonas. La cantidad disponible proviene del plan comercial y el DELIVERY elige cuáles operar.

Zonas disponibles para este DELIVERY

Solo se muestran zonas activas del mismo cantón. El plan determina cuántas pueden estar activas y el DELIVERY_ADMIN selecciona directamente cuáles utilizar.

Modo de acceso

Horarios de acceso

Ejemplo: red abierta de día y privada desde las 18:00 hasta las 06:00. Los horarios pueden cruzar medianoche.

Contactos autorizados

Importa hasta 500 contactos por lote. En modo privado, un cliente podrá entrar por coincidencia de teléfono o correo si el plan incluye esta función.

Formato: nombre, teléfono, correo. También acepta punto y coma. Teléfono o correo son obligatorios.
